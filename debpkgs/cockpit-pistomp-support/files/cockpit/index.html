Support logs

Generate a diagnostic archive you can download and send to pi-Stomp support. Nothing is uploaded from this page — you choose where to send the file.

Privacy notice

The archive includes system journals, service status, package versions, and basic hardware/audio/network state. Before the archive is written, the collector redacts:

  • IP and MAC addresses
  • Email addresses and /home/… usernames
  • WiFi SSIDs, passwords, tokens, and SSH key material
  • USB serial numbers

WiFi credentials, NetworkManager connection profiles, pistomp.conf, SSH host keys, and password hashes are never collected.

A short note you type below is included as you write it (not redacted). Do not put passwords or personal contact details in that note unless you intend support to see them.
